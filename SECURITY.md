# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security vulnerabilities seriously.

**Please do NOT report security vulnerabilities through public GitHub issues.**

Instead, please report them via:

1. **GitHub Security Advisory** (preferred): Use the "Report a vulnerability" button in the Security tab.
2. **Email**: Send a description of the vulnerability to the repository maintainers.

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Possible mitigations
- Your contact information

### Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial Assessment**: Within 5 business days
- **Resolution**: Coordinated with the reporter

### Disclosure Policy

We follow **coordinated vulnerability disclosure**. Please give us reasonable time to fix the issue before public disclosure.

Thank you for helping keep this project secure!
